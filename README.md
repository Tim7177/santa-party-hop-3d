# 🎄 圣诞跳一跳 · Santa's Party Hop 3D

一款基于 **Three.js + TypeScript + Vite** 打造的 **3D 圣诞派对主题《跳一跳》** Web 游戏。

🎮 **立即在线游玩**：[https://tim7177.github.io/santa-party-hop-3d/](https://tim7177.github.io/santa-party-hop-3d/)

## ✨ 核心玩法与亮点

- **经典蓄力跳一跳手感**：支持鼠标左键、手机触屏及键盘 `空格键` 长按蓄力、松开跳跃；蓄力时角色与圣诞平台同步弹性下压，松手起跳空中 360° 前空翻，精准命中中心可触发递增连击（`PERFECT ×N`）。
- **纯 Web Audio API 圣诞音乐与音效**：
  - 零外部音频依赖，自带温馨圣诞八音盒循环背景音乐。
  - **连续命中中心（Perfect Combo）** 会逐音符奏响《Jingle Bells》经典旋律！
- **3 款可自由切换的 3D 圣诞主角**：
  - 🎅 圣诞小老人
  - ⛄ 围巾小雪人
  - 🦌 发光红鼻鲁道夫
- **14 种圣诞微缩 3D 平台 & 6 大互动彩蛋图鉴**：
  - 🎁 **神秘圣诞盲盒**：在发光“？”礼盒停留 1.35 秒触发礼盒震开，奖励加分与「圣诞护盾」（免除一次失足掉落！）。
  - 🎵 **派对黑胶留声机**：停留 1.35 秒放下唱针，开启全场动态霓虹派对灯光并演奏《We Wish You a Merry Christmas》。
  - 🎄 **星光圣诞树奇迹**：在圣诞树台座停留 1.15 秒，自下而上逐层点亮七彩彩灯与树顶金星。
  - ⛄ **打瞌睡的雪人嘉宾**：跳上冰台震醒瞌睡小雪人，它会兴奋蹦跳抛礼帽撒雪花！
  - 🔥 **壁炉与圣诞袜**：在暖炉台停留 1.35 秒烤火暖身，圣诞袜掉落双倍星星糖，接下来 3 跳得分翻倍！
  - 🛷 **驯鹿雪橇飞跃夜空**：达成 3 连 PERFECT、总分突破 45 分或在星空许愿台停留，即可召唤 3D 发光驯鹿雪橇拖拽银河星尘划破夜空！
- **贴心星尘落点指引（可选练习模式）**：点击右上角 `✨` 按钮可随时开关抛物线星尘指引，休闲赏景与硬核挑战两不误。

## 🚀 本地运行

```bash
npm install
npm run dev
```

打开浏览器访问控制台打印的本地地址（默认 `http://localhost:5173`）即可畅玩！

## 📦 生产构建

```bash
npm run build
npm run preview
```
